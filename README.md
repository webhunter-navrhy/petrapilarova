# Petra Pilařová — travel design (návrh webu)

Jednostránkový web: Srí Lanka & Maledivy, skupinové zájezdy, průvodcovství, letenky.

- Upravuj `src/index.html`, `src/style.css`, `src/main.js`
- `python3 build.py` → vygeneruje `index.html` (mapa Srí Lanky s trasou z Natural Earth + ?v= hashe)
- Fotky: Unsplash (volná licence), zdroje v `assets/img/credits.json`
